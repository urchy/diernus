One-line: small mono pill for chapter jump-links, material lists and deliverable lists.

```jsx
<Chip href="#cap-01">01 · IDEIA</Chip>
<Chip href="#cap-04" tone="stamp">04 · A PEÇA</Chip>
<Chip>Valchromat</Chip>
```

Notes: always uppercase. `tone="stamp"` marks the current/most important item in a row.
