One-line: the sole Diernus button — mono uppercase text in a pill; cobalt fill for the ask, hairline ghost for everything secondary.

```jsx
<Button href="mailto:estudio@diernus.com">Falar com o estúdio →</Button>
<Button variant="ghost">Ver as pranchas</Button>
<Button variant="bar" size="sm">FALAR CONNOSCO</Button>
```

Notes: primary carries `--shadow-blue` and lifts 2px on hover, settling on press. Never more than one primary per section. Copy is uppercase mono and often ends in `→`.
