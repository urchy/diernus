One-line: the horizontal title block from a technical sheet — mono label over mono value, divided by hairlines.

```jsx
<TitleBlock items={[
  { label: 'Folha', value: 'L-SE-01' },
  { label: 'Escala', value: '1:20' },
  { label: 'Revisão', value: 'R3' },
  { label: 'Data', value: '28/05/2026' }
]} />
```

Notes: everything inside is uppercase mono. Four items on desktop, two per row on mobile.
